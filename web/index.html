Detecting connected cars that send false messages

Connected cars broadcast their position several times a second, and the cars around them act on it. Each message is signed, which proves which car sent it but says nothing about whether the position is true.

How often each attack is flagged

The baseline detector flags flooding, fake identities and random positions most of the time. Steady position offsets and replays are mostly classified as honest, which is the problem the rest of this work takes on.

One receiver cannot detect a steady position offset

A car that shifts every claim by the same amount keeps a consistent track, so content checks score zero on it. At a single receiver, the weaker signal from a car that is really farther away looks the same as ordinary fading.

the best F1 any of five learning methods reached with one receiver

Pooling measurements across receivers detects larger lies

Fading differs from one receiver to the next, while a false position affects all of them. Pooled received power detects position lies above a size threshold. Pooling the receivers' individual verdicts detected none.

A map check covers the receivers' weak direction

The receivers sit roughly in a line along the road, so they measure position across the road poorly. An informed attacker would lie in that direction, which moves the claimed position off the road, where a map check rejects it.

Roadside units can train the detector without sharing data

Each of the units trains on its own traffic and sends only model updates. The result was scored on cars that no unit had heard.

of central training's score on test, and on validation

Secure aggregation, which hides each unit's update from the server, made no measurable difference. With no server at all, each unit scored lower at times a FedAvg client's traffic, or lower at times.

When traffic or radio conditions change

Moved into new conditions unchanged, the detector fails mostly through false alarms. Refitting its input scaling on unlabelled local traffic recovered most of the loss for denser traffic and for weaker radio. Each card is a separate test.
